# ElectroSchem 1.3.0rc17

## Settings and assistant

- The OpenAI model ID is editable when OpenAI is selected and is preserved when
  settings are saved. Invalid model IDs are rejected with a clear message.
- The manual and assistant documentation now describe the visible question-
  and-answer interface; obsolete terminal shortcut instructions were removed.
- Renamed the assistant dock to match its current purpose.

## Regression coverage

- Added a settings regression for changing and saving the OpenAI model ID.
- Updated release-version expectations and the catalog-count assertion.
- Updated retired-console tests to assert that the old shortcut does not expose
  the hidden terminal.
- Updated asset-case tests to account for required light and interaction
  regions, and to test the current dashed-line connection workflow.

## Verification

- The full test discovery did not finish within its 60-second bound, so it has
  no suite-wide pass count.
- Syntax parsing passed for all 228 Python files.
- Focused AI-settings, wire, canvas, main-window, and asset tests are recorded
  in the final test report in the task chat.
