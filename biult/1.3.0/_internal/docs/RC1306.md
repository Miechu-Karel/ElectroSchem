# ElectroSchem 1.3.0rc6 — kandydat, nie wydanie końcowe

## Edytor obudowy

1. Zaznacz elementy i zapisz jako Asset z obudową.
2. Narysuj obrys ołówkiem, prostokątem lub kołem. Ołówek ze Shiftem
   rysuje prostą linię; powrót blisko początku zamyka odręczny obrys.
3. Ustaw wielkość obszaru obudowy i miniaturyzację układu wewnątrz.
4. Narzędziami IN/OUT dodaj piny na krawędzi obszaru. Nadaj im nazwy.
5. Narzędziem Połącz kliknij pin obudowy, następnie zielony pin układu.
   Widoczna linia reprezentuje trwałe przypisanie połączenia, nie zmienia
   oryginalnego obwodu. Każdy pin obudowy musi być podłączony przed zapisem.
6. Zapisz. Przy kolejnym otwarciu wracają rysunek, piny i przypisania.

Narzędzia mają tymczasowe ikonki. Ctrl+Z i przycisk Cofnij działają dla
rysowania, gumki, dodawania, łączenia, nazw i przesuwania pinów oraz wymiarów
i miniaturyzacji. Gumka usuwa cały wskazany kształt/ślad lub pin, nie piksele.
Kółko myszy przybliża; Dopasuj widok przywraca widoczność całej zawartości.
Zmiana rozmiaru skaluje rysunek i przenosi piny na nową krawędź.
Piny są na siatce 20, wymiary obudowy są wielokrotnością 40.

Nowa obudowa zaczyna bez automatycznych pinów. Zapisane obudowy zachowują
dotychczasowe piny i można zmieniać ich połączenia. Zmiana liczby/numerów
pinów assetu już użytego na schemacie jest blokowana, aby nie podmienić
istniejących sygnałów. Nowe i nieużywane assety nie mają tego ograniczenia.
IN/OUT oznacza przeznaczenie pinu, nie narzuca kierunku przepływu prądu.

## Przewody

Przewody skośne po przesunięciu nadal mają odcinki poziome, pionowe albo
45°. Geometria pojedynczego przeciągania jest liczona względem początku
gestu, bez narastania zakrętów w kolejnych klatkach. Ruch komponentów
nadal nie scala niepowiązanych sieci. Trasy ortogonalne AI są zachowane.

Testy lokalne nie potwierdzają działania Gemini po odnowieniu limitów:
nie wykonano rzeczywistych zapytań API ani nie zmieniono wersji na 1.3.0.
