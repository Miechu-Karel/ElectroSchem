# ElectroSchem 1.3.0rc24

- Removed the intermediate **Przyrządy pomiarowe** subcategory; measuring instruments are listed directly.
- Added **Porty USB**, **Goldpiny** and **Kable** subcategories under **Kable i złącza**. Other connectors stay visible at the root of that category.
- Updated the in-app bilingual usage instructions, README and release version.
- New project saves use ELS format version 4. Releases that support only ELS v1–v3 reject these files, preventing accidental opening in an older app.
