# ElectroSchem 1.3.0rc9

## Local AI and LM Studio

- Local requests bypass system proxies so loopback AI servers receive requests directly.
- OpenAI-compatible requests use a strict JSON schema for assistant answers and plans.
- HTTP error responses include the server's short error detail; API tokens are redacted.
- Local model answers in `reasoning_content` are accepted when `content` is empty.

## Assets

- The selection rectangle snaps to the schematic grid.
- Boxed assets cannot be saved until light and interaction regions are assigned to components that need them.
- Asset members can be marked as editable in the case editor.
- Unboxed assets may be grouped as one object or left as independent elements; Shift temporarily allows picking a member of a group.
- Asset membership is limited to passive parts, semiconductors, lights/IR, eligible switches, buzzers, and allowed IC families. Excluded IC groups remain excluded.
- Case light windows use a distinct off-state and intensity-scaled glow.

## Simulation and labels

- Tight Python `while` loops cooperatively yield to the simulator; GPIO PWM supports `start`, `ChangeDutyCycle`, `ChangeFrequency`, and `stop`.
- The membrane keypad is displayed as **Keypad 4x4**, while its saved library ID remains compatible with existing projects.
- The USB keyboard preview has a wider, more conventional layout to reduce clipped labels.
