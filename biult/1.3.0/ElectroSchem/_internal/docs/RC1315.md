# ElectroSchem 1.3.0rc15

## Custom asset behavior

- LED windows use the same brightness-dependent alpha, colour palette and RGB channel override as standalone LED glows.
- Interaction windows reuse the simulator's controls for potentiometers, variable resistors, joysticks and keypads. Momentary controls now follow press/release semantics.
- Potentiometers and variable resistors can be chosen as interaction targets in the case editor.

## Case editor

- Each drawing gesture starts with a fresh origin; changing tools or refreshing the preview cancels any stale draft.
- The variable-resistor arrow points upward.

## Resistance values

- Variable-resistor limits are compared after SI-prefix conversion, both when saving properties and when loading a circuit.
- Live resistance displays use engineering prefixes (for example, `14.55 EΩ` instead of scientific notation).

## Verification

- Catalog and simulation tests pass, including variable-resistor range and SI-format regressions.
- Python files pass syntax parsing. Qt GUI interaction could not be exercised in this runtime because PySide6 is unavailable.
