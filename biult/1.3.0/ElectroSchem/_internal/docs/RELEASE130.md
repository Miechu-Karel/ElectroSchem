# ElectroSchem 1.3.0

ElectroSchem 1.3.0 is the official stable release promoted from the tested
1.3.0rc25 candidate.

- Added the **Terminale** subcategory under **Kable i złącza**.
- New project saves use ELS format version 4; releases that only support v1–v3
  refuse to open them. Older project files remain readable and are upgraded
  when saved by this release.
- Includes the changes documented for [RC25](RC1325.md) and earlier candidates.

See [README](../README.md) for portable-build and compatibility information.
