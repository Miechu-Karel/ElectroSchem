# ElectroSchem 1.3.0rc18

## Schematic wiring

- Wire previews keep the bend anchored to the starting endpoint while the
  cursor moves; blocked routes still fall back to the legal grid router.
- Drawing continues from a free endpoint, while landing on a component pin
  finishes the wire chain.
- Junction dots are drawn only when three or more distinct wire directions
  meet, not for a simple bend or redundant collinear endpoints.

## Measurements and assistant interface

- Measurement help now explicitly says to connect voltage meters in parallel
  and current meters in series, and warns against placing an ammeter across a
  source.
- The assistant shows a short answering status, hides the assistant tab strip,
  and groups Send/Stop and Edit/Regenerate into two rows of two buttons.
- User-facing AI error explanations no longer refer to schematic editing.

## Oscilloscope

- The inline seconds/division controls change by 0.01 per arrow press.
- Clicking or dragging over the waveform displays a cursor and the interpolated
  instantaneous voltage at that time.

## Verification

- Focused regressions cover wire-route stability, free-end wire continuation,
  branch-dot behavior, oscilloscope cursor interpolation and control steps.
- All 227 application and test Python files pass syntax compilation.
- The Qt test suite could not run in the available bundled Python because
  PySide6 is not installed there.
