# ElectroSchem 1.3.0rc12

## Custom asset case editor

- Light and interaction windows can be linked explicitly with the Connection tool: click the window, follow the green dashed guide, then click the target component's selection area.
- The guide line remains visible and is saved with the asset after connection.
- The selection geometry used for connection now survives editor redraws; previously the paint editor discarded the component hit areas before processing the second click.
- Light windows target emitting components; interaction windows target supported interactive components.
- Paused simulations also recalculate immediately after toggling an internal switch; this is a separate safeguard and does not explain the reported behavior while the simulation is running.
- Each case shell now resolves its internal component IDs with the same stable instance-scoped mapping as the expanded simulation circuit, preventing a window from reading a sibling module's LED state if component ordering differs.

## Verification limits

- Changed modules pass Python syntax parsing.
- Full live Qt simulation was not available in this environment; verify the light output with two separate instances of the same custom asset.
