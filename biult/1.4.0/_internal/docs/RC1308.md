# ElectroSchem 1.3.0rc8

## Obudowy assetów

- Jedno narzędzie **PIN**, zamiast IN i OUT. Terminale nie narzucają kierunku sygnału.
- Dodawanie i przesuwanie pinów przyciąga do siatki 20 jednostek; piny nie wychodzą poza obszar edytora. PIN można umieścić w dowolnej części obszaru, nie tylko na jego ramce.
- Kreska łączy terminal z najbliższą krawędzią narysowanej obudowy w pionie lub poziomie. Aby wystawała poza obudowę, ustaw PIN o kratkę poza jej obrysem.
- Narzędzie **Pole zaznaczania**: przeciągnij prostokąt. Zmienia wyłącznie obszar klikania/zaznaczania assetu, nie skaluje układu ani pinów. Obsługuje Ctrl+Z i zapis w ELS/bibliotece assetów.
- Okno świecenia domyślnie wybiera element świecący; interakcja wybiera obsługiwany przycisk/przełącznik. Wybierz właściwy element z listy przed narysowaniem okna. Samo obrysowanie elementu nie tworzy połączenia elektrycznego.
- Świecenie pobiera jasność i RGB z wyniku obliczeń; kliknięcie obszaru przycisku naciska go, puszczenie zwalnia. E nad tym obszarem działa tak samo. Interakcje obejmują akcje dostępne pod E dla konkretnego modelu; nie emulują automatycznie wszystkich interfejsów dowolnego układu.
- Zapisana obudowa pokazuje zewnętrzną obwiednię obszarów rysunku, nie bazgroły i krawędzie w środku. Dwupunktowa linia poza obrysem pozostaje kreską; ślad ołówka z co najmniej trzema punktami wyznacza obszar.
- W symulatorze ukryte są także wewnętrzne odcinki przewodów pomiędzy węzłami, nie tylko odcinki dochodzące do elementów.

## Przewody i kable

- Rozciąganie przewodów usuwa zbędne współliniowe zagięcia i zamknięte objazdy wewnątrz pojedynczego przewodu. Nie zmienia identyfikatorów końców ani węzłów rozgałęzień między przewodami.
- Kolejne przesunięcia nie dokładają bez końca terminalnych zagięć. Nachylenia pozostają pionowe, poziome lub 45°.
- Końcówki kabli w edytorze nie wychodzą poza obszar roboczy ani nie wchodzą w tabliczkę rysunkową. Sandbox symulacji pozostaje bez ramki arkusza.

## Lokalne AI i błędy

- Kliknięcie błędu otwiera informator z przyciskiem **Kopiuj błąd**.
- Opcjonalny token lokalnego API w ustawieniach; nagłówek `Authorization: Bearer …` jest wysyłany wyłącznie do zwalidowanego serwera loopback. Token jest maskowany, chroniony Windows DPAPI i nie trafia do ELS.
- HTTP 401 nie oznacza, że serwer nie działa: odrzucono uwierzytelnianie. W LM Studio: Server Settings → Manage Tokens; wpisz token w ustawieniach AI ElectroSchem.
- Lokalizacja błędu zachowuje kod HTTP, również dla przerwanego ćwiczenia. Błędy endpointu i uwierzytelniania mają osobne objaśnienia.
- Użyj dokładnego portu widocznego w LM Studio, a nie na siłę domyślnego 1234. Klient używa endpointu OpenAI-compatible `/v1/chat/completions`.

Diagnostyka 13.10.2026: odczyt listy modeli bez tokenu na `http://127.0.0.1:1/v1/models` zwrócił HTTP 401; port 1234 nie odpowiadał. Nie wysyłano poleceń do modelu, nie wyłączano uwierzytelniania, nie zmieniano konfiguracji LM Studio.
