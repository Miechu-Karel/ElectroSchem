# ElectroSchem 1.3.1alfa1

- Large selection drags no longer run costly shortest-route searches for every mouse move. The preview uses the moved geometry, then recalculates affected shortest legal routes in a background worker after release.
- Background route results are discarded or retried when the sheet changes, and are folded into the drag's existing undo state.
- Reduced the dark-theme sheet, grid and title-block brightness by about 15%.

This is a development alpha before cloud-save work. It is not an official stable release.
