# ElectroSchem 1.3.0rc20

## Schematic wire movement

- Moving a shared wire junction now snapshots the original routes for the
  entire mouse gesture. Rerouting no longer accumulates bends frame by frame.
- Wires incident to the same moving junction are routed as one movement group,
  preventing stale sibling routes from introducing short stray elbows.

## Test status

- Focused regression coverage compares direct and incremental junction moves.
- Full application and interactive testing is pending.
