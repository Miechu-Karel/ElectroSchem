# ElectroSchem 1.3.0rc19

## Schematic wiring

- Completing a wire now cancels its preview and anchor. A following wire starts
  only after the user clicks a new start point.
- Isolated, unconnected wire endpoints show node dots. Shared bends and
  component-pin endpoints remain unmarked unless they form a branch.
- Canvas fitting is debounced and skipped while the window is minimized to
  reduce redraw work during minimize/restore.

## Test status

- Full application testing is pending; it is intentionally deferred until the
  user is available to test the release candidate.
