# ElectroSchem 1.3.0rc21

- Navigation and numeric keypad buttons in the USB keyboard simulator are square.
- The photoresistor now has an illumination slider, from darkness to its reference-light level.
- Added the **Interactive components** category and English-named icon `interactive_components.png`.
- RFID cards are in the interactive category; their previous library ID remains valid for saved projects.
- Added a movable match: click to light/extinguish it, then drag a lit match near a flame sensor to change the sensor's simulated signal.
- Added an ultrasonic reflector target and a person/heat-source prop for HC-SR04 and PIR stimulus.
- Added an IR remote prop that sends a short active-low pulse to a nearby IR receiver (without emulating carrier or protocol encoding).
- Analog sensor outputs now have direct sandbox sliders; HC-SR04 distance also has a slider, overridden by a nearby reflector target.
- Audited sensor stimuli: RFID, flame, ultrasonic distance, PIR presence, IR receiver, LDR illumination and analog sensor values now have a corresponding card, scene prop or direct control. Modules represented only by a supply-envelope model are not given fictitious sensor behavior.
- RFID cards, matches, the target, person, remote and flame-sensor boards use more recognizable physical-style graphics.
