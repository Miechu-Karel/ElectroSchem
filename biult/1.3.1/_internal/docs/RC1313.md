# ElectroSchem 1.3.0rc13

## Custom asset simulation

- Light windows now use the same `0.001` brightness cutoff as standalone component glows. Tiny positive leakage current no longer paints a full-strength red window when the LED is effectively off.
- Interaction windows dispatch through the simulator's normal component-input handler, rather than synthesizing a keyboard `E` event. Their active appearance reflects the actual device state for switches, momentary buttons, sensors, keypads and logic inputs.
- Window regions remain instance-scoped, so each copy of an asset reads its own internal component IDs.

## Case editor clarity

- Width and height controls now use full labels. Their values are drawing units (20 units per grid square).
- The pin-name field, clear-pins action and unconnected count have explanatory tooltips.
- Editable-member checkboxes now explain that checked components expose their properties after the asset is placed.
- Routed green guide lines remain visible and saved for light and interaction windows.

## Verification

- Changed Python files pass syntax parsing. Qt integration tests could not be run in this environment because PySide6 is not installed in the available Python runtime.
