# ElectroSchem 1.3.0rc11

## Assistant and settings

- The assistant UI is temporarily limited to questions and explanations. The drawing planner, proposal editor, and editor-terminal implementation are retained but hidden and not invoked.
- The local-AI setup tutorial is shown only when Local AI is selected as the provider.

## Asset cases

- Removed the inner-circuit miniaturizer. Legacy scale values remain accepted but are ignored, so old assets still load and inner content renders at full scale.
- Added an option to show or hide exported pin names; hidden by default to avoid crowded custom symbols.
- Pin numbers are reassigned sequentially in the current list order after add/remove. A stable internal identity preserves existing wire attachments when displayed numbers shift.

## Wire routing

- Automatic routing now ranks valid paths and prefers 45-degree elbows over right-angle bends when possible.
- A simple stretched two-point wire also recalculates with the 45-degree router.

## Case editor and icons

- Replaced the pin-only move action with an edit tool: drag pins and existing shapes, move complete shapes, and drag an individual rectangle/ellipse edge to resize it.
- Renamed the supplied icon files to English names and connected them to the editor, app, and simulator controls. The app now loads them from `icons/`.
- Toolbar labels are kept at full width in a horizontally scrollable strip. The “Connection” tool can link a light window to an overlapping emitting component as well as link package pins.

## Verification and limits

- No external AI provider or local model was contacted.
- Existing legacy pin attachments still depend on the stored pin number/name data and should be inspected after editing older custom components.
- Placeholder icon assets are still used in the Paint-style case editor; see the handoff list in the release notes.
