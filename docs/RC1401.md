# ElectroSchem 1.4.0rc1

## Changes

- Wire endpoints left floating after detaching or deleting a connection now
  refresh their node markers immediately.
- Removed Dropbox and Nextcloud support. The cloud-provider list is now ordered
  **No cloud**, **GitHub**, **Google Drive**, **OneDrive**.
- Legacy Dropbox/Nextcloud selections migrate to **No cloud**; legacy provider
  credentials are discarded when settings are next saved.
- Every successful `.els` save creates a Git commit for that file, including
  saves whose contents are unchanged. Commit subjects contain the filename and
  local date/time with time-zone offset.
- Manual GitHub push sends the configured branch and all commits not yet present
  on the remote. A post-commit check catches saved files that Git left modified.

## Verification

Regression tests cover detached-wire nodes, cloud-provider ordering and
migration, commits of modified and newly added project files, one commit per
save, filename/timestamp commit subjects, and pushing complete branch history.
