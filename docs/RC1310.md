# ElectroSchem 1.3.0rc10

## Assistant and local AI

- Introductory AI exercises are enabled again.
- Invalid command proposals receive one bounded correction attempt using the exact validation error. This covers parser errors, command application errors, and exercise simulation/truth-table failures. The editor project remains unchanged until the user accepts a valid proposal.
- If a local OpenAI-compatible server rejects JSON Schema response format with HTTP 400, ElectroSchem retries once using JSON-object mode. Other HTTP 400 errors are not retried as format errors.
- Stopping a request cancels pending correction/compatibility retries.
- The local AI confirmation accounts for the optional compatibility retry and correction pass.

The correction request is sent to the same selected provider/model and may use the same project context as the original request. Local AI is sent only to the configured loopback server. Cloud requests may incur additional provider charges.
