# ElectroSchem 1.4.0rc2

## Changes

- Recalculate wire-end markers after endpoint attachment, component movement,
  component-property edits, and wire removal.
- Every endpoint with no valid component pin and no other endpoint connected to
  it shows a node marker.
- Existing shared junction IDs are considered when deciding whether endpoints
  are connected, including older projects with slight coordinate drift.
- Kept the branch-dot rule: two-wire bends are unmarked; real branches keep a
  junction dot.

## Verification

Regression tests cover isolated wires, connecting and removing a neighboring
wire, component movement attaching a loose end to a pin, invalid pin anchors,
legacy coordinate drift with a shared junction ID, and existing bend/branch
behavior.
