# ElectroSchem 1.0.0 - portable Windows x64 build

Run `ElectroSchem.exe` and keep the complete `_internal` directory beside it.
No separate Python installation is required. This package is rebuilt from
the original source release commit `7be1dec` and is kept separate from current
application releases.

This historical release is provided for versioned archival and comparison;
it does not receive current fixes. The executable is unsigned, so Windows may
show an unknown-publisher warning.
